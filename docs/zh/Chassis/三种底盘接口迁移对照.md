# 三种底盘接口迁移对照

三种底盘统一接收车体系 `speedx、speedy、speedw`：前进和左移的线速度使用 m/s，自转角速度使用 rad/s，逆时针为正。摇杆与命名的完整定义见[底盘坐标与速度接口约定](底盘坐标与速度接口约定.md)。

先完成麦轮、全向轮的接口和测试，舵轮再逐项处理旧映射。尚未符合约定的实现继续标为旧接口。临时转换集中放在调用旧接口的位置，便于核对和移除。

下表列出旧实现与目标接口的差异，不代表旧代码已经通过新接口验收。

## 三种底盘分别需要改什么

| 项目 | 舵轮 | 全向轮 | 麦克纳姆轮 |
|---|---|---|---|
| 旧轴向 | 包含 `Vy = -speedy`、yaw 取负和特定舵角投影 | 驱动库旧轴图为右 X、前 Y | 内部模型已为前 X、左 Y |
| 轴向迁移 | 拆出安装映射，按标准轮位重建速度矢量 | 按标准轮位与每轮正滚动方向重写对应投影 | 保留车体系轴向，核对辊子装配和轮号 |
| 世界 yaw | 旧控制与反馈都有 yaw/符号转换 | 旧控制按 yaw 旋转，反馈转回世界系 | 旧对外输入、输出为世界系 |
| 车体系入口 | 移出 yaw 转换及 `world_angle` 依赖 | 移出正逆解算的 yaw 转换 | 移出正逆解算的 yaw 转换 |
| 旧旋转输入 | `speedw` 实际按轮心切向线速度参与计算 | 输入角速度，内部乘 `OMNI_RADIU` | 输入角速度，内部乘模型旋转系数 |
| 旋转迁移 | 直接接收角速度，从轮位计算旋转分量；取消调用层预乘半径 | 显式配置实际旋转几何，核验正旋转符号 | 保留模型旋转系数，调用层不另乘半径 |
| 旧几何配置 | 初始化半径与文件内宽长比例分开配置 | 轮数、投影系数和 `OMNI_RADIU = 1.0f` 固定 | 初始化已有轮径、半轴距、半轮距和 X/O 装配 |
| 初始化迁移 | 轮位和半径由同组尺寸推导，明确轮径与轮端边界 | 显式配置轮径、轮位和滚动方向，或明确支持的固定布局 | 保留尺寸和装配校验，取消车体系入口的 yaw 参数 |
| 旧轮端速度 | 轮缘线速度；历史工程为 mm/s，舵角为 rad | 驱动库输出轮缘线速度，没有除车轮半径 | 输出轮轴 rad/s |
| 轮端迁移 | 统一为轮轴 rad/s 与标准舵角 rad，转换命令和反馈 | 输出除轮径、反馈乘轮径，各做一次 | 保留轮轴 rad/s，核对硬件回调不重复换算 |
| 正解算迁移 | 与新轮位及舵角投影对应，输出同一车体系三分量 | 与新投影、几何、单位对应 | 保留车体系组合公式，移除末尾世界系旋转 |
| 状态与功能 | 保留最小转角、反向滚动等价选择和停车保持角度 | 不需要舵角状态，保持固定轮向投影 | 保留装配类型与退化布局校验 |
| 边界检查 | 单轮合速度为零时不除零，驻停角与矩形布局一致；旧三轮反馈分支需独立实现 | 三轮与四轮分别验证，不能套用同一符号结论 | 当前 O 型正方形模型自转退化，应拒绝无效初始化 |

站内参考代码：[舵轮](steering_wheel/steering_wheel.c)、[全向轮](omni_wheels/omni_wheels.c)、[麦轮](mecanum_wheels/mecanum_wheels.c)。历史舵轮分析见[旧版全链路坐标说明](steering_wheel与底盘全链路坐标轴约定.md)，其中的内部轴向不能代替新接口定义。

## 用轮位统一几何含义

半轴距为 `a`、半轮距为 `b` 时，统一四轮下标为左前、右前、左后、右后：

| 下标 | 位置 | 车体系轮位 |
|---|---|---|
| 0 | 左前 | `(+a, +b)` |
| 1 | 右前 | `(+a, -b)` |
| 2 | 左后 | `(-a, +b)` |
| 3 | 右后 | `(-a, -b)` |

轮位处的二维速度为：

```c
wheel_speedx[i] = speedx - speedw * wheel_y[i];
wheel_speedy[i] = speedy + speedw * wheel_x[i];
```

舵轮用它求轮缘速度和舵角；全向轮再投影到主动滚动方向；麦轮按辊子约束组合。三者共享车体速度定义，但不能共享一套轮速公式。

车轮半径用于线速度与轮轴角速度换算。底盘旋转几何则决定自转造成的轮位速度。矩形轮心到中心的距离为 `sqrt(a*a+b*b)`，但麦轮当前 X 型旋转系数为 `a+b`、O 型为 `b-a`，不能全部替换成一个“底盘半径”。

全向轮的滚动方向固定，不需要最小转角选择、舵角反馈或停车角度状态，所以代码通常更短。迁移时补齐实际几何、单位和轮端方向即可，不必增加同舵轮一样多的状态。

## 旧舵轮为什么不能只交换 XY

一种旧调用方式是：

```c
steering_wheel_ctrl(speed_x, speed_y,
                    speed_yaw * CHASSIS_RADIUS_MM);
```

调用者已经将角速度乘以半径。以 `1 rad/s` 与 `443.84 mm` 为例，传入第三参数的是 `443.84 mm/s`。旧正解算再除以半径，才得到 rad/s。输入和输出虽然都叫 `speedw`，物理量并不相同。

该实现还使用 deg 的 `world_angle` 和 rad 的舵角，并含轮端安装映射。迁移时应分别核对：

1. 车体平移的轴向与正负。
2. 角速度到旋转线速度的换算位置。
3. 世界系转换是否仍应出现在调用链中。
4. 实际舵角零点、正方向及最小转角等价变换。
5. 反馈的逆变换和单位。

每次改一项，并验证对应行为。保留旧实现期间，新入口通过单独的适配调用它；只有轴向、单位和反馈都符合约定，才算完成迁移。

## 不同工程的相同名字可能代表不同量

R1、R2 的旧代码中，有些名字相似，实际存放的量却不同。两者使用的实现也不同，核对时要对应到具体工程。

| 对比项 | R1 旧执行链 | R2 旧执行链 | 统一方式 |
|---|---|---|---|
| 车体三分量 | `speed_x/speed_y/speed_yaw`，mm/s 与 rad/s | `vx/vy/vw`，m/s 与 rad/s | `speedx/speedy/speedw`，m/s 与 rad/s |
| `chassis_speed_t` | 车体速度并混有航向与驻停状态 | 四个 `target_rpm` | 类型只表示三个车体速度；电机命令和状态分开保存 |
| 遥控平移 | 旧通道 X/Y 直接进入旧底盘速度 | 旧水平取负作为 Y，旧垂直作为 X | 发送端统一轴向后，接收端同轴正比例映射 |
| 遥控转向 | 旧右水平通道 | 旧右水平通道并取负 | 保留左右推转向时，统一使用新 `right_y` |
| 电机目标 | `speed_motor_target` | `target_rpm`、`out_wheel_rpm` | 已乘减速比的量命名为 `target_motor_rpm` |
| 反馈变量 | 直接读取驱动 `speed_rpm` | `real_rpm`、`measure_rpm` | 业务层使用 `feedback_motor_rpm` |
| 换算命名 | `wheel_mmps_to_rpm`、`wheel_rpm_to_mmps` | `MPS_TO_RPM`、`RPM_TO_MPS` | 名称同时说明轮缘速度单位和电机轴 RPM |

例如 R2 的 `out_wheel_rpm` 已通过含减速比的公式换算，实际是电机轴 RPM，不能因为名称有 wheel 就再次乘减速比。旧 R1 的 `wheel_rpm_to_mmps()` 输入同样来自电机反馈，适合改为明确的 `motor_rpm_to_wheel_mmps()`。

ROS 或线上协议已有的 `linear_x/linear_y/angular_z` 可以保留，接收后再对应到标准三分量。通用轨迹规划器也保留自己的数学变量；只有表示同一物理量的业务字段才统一命名。

## 遥控切换会影响哪些消费者

| 旧功能 | 新逻辑通道 | 迁移时检查 |
|---|---|---|
| 左摇杆前后控制前进后退 | `left_x` | 接收端不再 X/Y 交叉赋值 |
| 左摇杆左右控制横移 | `left_y` | 左推为正，不保留旧纠正负号 |
| 右摇杆左右控制自转 | `right_y` | 新四通道数组为 `rs[3]` |
| 右摇杆前后控制升降 | `right_x` | 新四通道数组为 `rs[2]`，核对前推对应的动作 |
| 关节控制复用摇杆 | 按原物理操作选择新 X/Y | 旧水平改读新 Y、旧垂直改读新 X，动作正负按机构确认 |

所有机构读取的摇杆轴向都相同。机构可以自行规定动作正负，但不能在某个模式里又把摇杆 X 解释成左右。

## 初始化与测试的边界

初始化负责保存几何、预计算系数、回调和必要状态，控制函数每周期接收三分量速度。已有“宏补默认参数后调用固定实现”的方式可以继续使用；它不自动提供运行时多态或多实例，也不能让同一个参数因初始化方式不同而改变单位。

| 验证层 | 需要确认 |
|---|---|
| 配置 | 实际轮径、轮位、轮号、正滚动方向、减速比及辊子装配 |
| 数学模型 | 六个基本方向、组合运动、非正方形尺寸、不同轮径和零输入 |
| 正逆一致 | 反馈恢复同一物理量，同时符合独立几何期望 |
| 轮端适配 | 目标和反馈的方向、减速比、RPM/rad/s 换算互逆 |
| 遥控协议 | 每根摇杆四方向、版本区分和所有字段消费者 |
| 实车 | 先低速逐方向，再验证速度大小及组合运动 |

如果纯自转输入产生四轮同号速度，而反馈公式只取会互相抵消的差分，正解算就可能把自转读成零。这样的矛盾属于模型问题，不能通过统一名称解决。类似地，RPM 上限注明电机轴转速时，换算轮缘线速度必须核对减速比，不能只相信注释。

修改前写清要改变的含义和验收方法。麦轮、全向轮先按标准入口测试；舵轮保留旧版作为对照，逐项修改到相同约定。
